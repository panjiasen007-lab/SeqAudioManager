## 5. 建议

1. 扫描期直接解析内嵌封面并写入 `Covers/`（把懒加载前移），避免首播才出图。
2. 重命名对 CUE 母文件改为「同步改写 .cue 的 FILE 行」，而不是直接跳过。
3. 封面搜索同样按「专辑 → 去专辑 → 仅曲名」降级，本轮 5 个候选匹配度均为 0。
4. 样例播种功能仅保留给 debug 构建，release 不内置示例曲目。
