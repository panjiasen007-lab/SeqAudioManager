# 音序管家 · HarmonyOS PC v1.3.7 发布说明

- 发布日期：2026-11-27
- 适用平台：HarmonyOS PC / 2in1（arm64 真机；HAP 同时包含 x86_64 原生库，便于模拟器验证）
- 应用版本：1.3.7
- 安装包：
  - 侧载：`SeqAudioManager-v1.3.7-harmony-arm64.hap`
  - 上架：`SeqAudioManager-v1.3.7-harmony-arm64.app`（App Pack）
- 签名：AGC **发布证书** `seqaudio-release` + **Release Profile**（`app_gallery` 分发、无设备白名单、有效期至 2029-11-27）
- 校验：同目录 `SeqAudioManager-v1.3.7-harmony-arm64.hap.sha256`；Profile `type=release`，`hap-sign-tool verify-app` 通过

## 本次更新

1. **透明度**
   - 主界面与迷你播放器统一为 **25–100%**，默认 **95%**。
   - 透明度变化增加 140ms EaseOut 缓动，拖动滑块不再突兀。
   - 窗口背景与容器透明，低透明度时能看到桌面透出。
2. **迷你播放器**
   - 独立 `MiniAbility` 窗口（560×320），按 Windows 版 1:1 横向布局。
   - 圆形旋转封面、单行歌曲标题、进度+时间、三行歌词当前行高亮。
   - 播放模式图标随 **顺序播放 → 列表循环 → 单曲循环 → 随机** 实时变化。
   - 上一曲 / 播放暂停 / 停止 / 下一曲 / 音量 / 静音 / 进度 / 透明度全部可用。
   - 窗口最大化与关闭均回到主界面；最小化保留到 Dock。
3. **主窗口**
   - 默认按屏幕 **84% × 80%** 居中窗口化启动，不再最大化。
   - 隐藏系统标题栏，品牌、状态、界面不透明度、最小化/最大化/关闭合并为一条自绘深色顶栏，只保留一个「音序管家」标题。
   - 状态徽标位于「界面不透明度」左侧；品牌区与中部空白均可拖动窗口。
   - 最大化后可通过同一按钮还原到默认窗口尺寸。

## 安装

```bash
# 安装 / 覆盖升级
hdc install -r SeqAudioManager-v1.3.7-harmony-arm64.hap
# 启动
hdc shell aa start -a EntryAbility -b com.seqaudio.manager
```

也可以在文件管理器中双击 HAP 安装（真机需允许安装未知来源应用）。

### 上架 AppGallery

`.app` 已使用 AGC 发布证书与 Release Profile 签名，可直接在 AppGallery Connect 创建版本并上传；改代码后重新构建并按 README「Release 签名」一节重新签名。

## 升级与卸载

- 覆盖安装（`hdc install -r`）会保留曲库、设置与播放会话。
- **从调试签名包（旧 v1.3.7 资产）升级**：因签名证书变更，覆盖安装会报 `9568332 install sign info inconsistent`，需先 `hdc uninstall com.seqaudio.manager` 再安装（会清空沙箱内曲库）。
- 卸载命令：`hdc uninstall com.seqaudio.manager`。卸载会删除应用沙箱内的曲库与音频文件，操作前请先导出备份。
- 从旧版本升级时，透明度会一次性迁移到新的默认值 95%；之后按用户设置保存（25–100）。

## 已知边界

- 已生成可上架的 `.app`（Release 签名），尚未提交 AppGallery 审核。
- 不含 Windows 版的 WASAPI/ASIO 独占、系统托盘、全局媒体键。
