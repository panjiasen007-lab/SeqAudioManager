# 音序管家 · 鸿蒙 PC v1.3「桌面界面 1:1 复刻」可执行计划

> 基线：`harmony-pc` @ `fa61800`（M2 出口回归通过）
> 对照：桌面版 `main` @ v1.8.2（Python + PySide6）
> 参考：`README.md`（桌面版）、`harmony/README.md`、`harmony/docs/REWRITE-PLAN.md`

## 0. 一句话目标

把鸿蒙版从「移动式单列页面」改成**和桌面版同一张工作台**：品牌条 → 操作栏 → 统计卡 → 曲库表格 + 右侧详情/参数 → 播放条 → 日志/歌词/信号路径 → 状态栏；交互按桌面版的手感做，做不到的能力明确删除，不摆假按钮。

**视觉命题**：深空蓝专业音频工作台 —— 近黑深底、玻璃质感面板、单一冰蓝强调色、密集但克制的数据行。
**内容计划**：主工作台（曲库）为唯一主角；辅助页只承担编辑、整理、体检、封面、歌词、EQ、关于。
**动效命题**：① 品牌条底部冰蓝渐变收口与静态星域；② 选中/播放行左侧强调条 + 淡强调底；③ 播放条玻璃卡与圆形播放键；④ 右侧面板与底部栏折叠。

## 2. 复刻边界（保留 / 改造 / 删除）

### 2.1 原样保留（能用且值得做）

- 品牌条、操作栏、统计卡、搜索/筛选、曲库表格、详情面板、播放条、底部日志/歌词、状态栏的**布局与配色**。

- 参数面板的 Card 结构和「还原 / 保存参数」底部操作条。

### 2.2 鸿蒙化改造

| 统计卡「假无损」 | 改为「高解析」卡（≥96kHz 或 DSD），并保留 待确认/失败 | 本版没有真假无损鉴定 |
| 判定筛选胶囊 | 改为「全部 / 无损 / 有损 / 高解析 / CUE」 | 同上 |
| 真假鉴定列 | 移除 | 同上 |

## 6. 核心算法阶段（v1.3.1，1:1 复刻桌面版）

### 6.1 模块与入口

| 能力 | 鸿蒙实现 | 桌面版对应 |
|---|---|---|
| 联网元数据匹配 | `net/MetadataProviders.ets` + `net/TextMatch.ets` + `pipeline/Matcher.ets` + `components/MatchDialog.ets` | `core/matching.py` / `net/*.py` |
| 一键全自动 | `pipeline/AutoRunner.ets` + `Index.startAuto/saveAllPending` | `pipeline/batch.py` |
| 真假无损 / 频谱 | `cpp/audio_analysis.cpp` + `core/AuthenticityService.ets` + `components/SpectrumDialog.ets` | `core/authenticity.py` + `ui/spectrum.py` |
| 清理假无损 | `core/CleanupService.ets` + `files/Quarantine` | `core/quarantine.py` |
| CUE 分轨导出 | `pipeline/CueSplitService.ets` + 原生 `exportSegment` | `pipeline/cue_split.py` |
| SACD ISO | `scanner/SacdParser.ets`（TOC/SACDText）+ `cue/CueIndexer.indexSacd` + 原生 `audio_stream_select.h` + FFmpeg SACD demuxer 补丁 | `core/sacd.py`（依赖 `sacd_extract.exe`）；鸿蒙版无外部二进制 |

### 6.2 匹配参数（与桌面版一致）

- 数据源优先级：网易云 → QQ 音乐 → MusicBrainz → iTunes；歌词：网易云 → QQ → lrclib。
- 评分权重：source 0.34 / title 0.28 / artist 0.20 / album 0.10 / duration 0.08。
- 默认自动应用阈值 62%（设置页可调 30–95%）；版本词惩罚 0.18；目录专辑 hint +0.14 / +0.05、冲突 -0.06。
- MusicBrainz：UA 标识 + 1.12s 限流，`artist-credit` 等连字符字段先转 camelCase 再解析。

### 6.3 鉴定参数与校准

- 采样：4 段 × 4s（DSD 2s），FFT 8192 点 Hann，s32 解码，双声道取功率较大者。
- PCM 判据：截止（峰值 -65dB）/ 陡度 / 250Hz 断崖（12dB）/ 扩展带（相对峰值与 300–3kHz 主体）/ 空洞 / sfb21 / 扩展带平坦度 / 升频台阶（18dB）/ 有效位深零填充。
- DSD 判据：50–100kHz 噪声整形斜率（≥6.0 真 / <0.5 假）、PCM Nyquist 断崖、CD 边界数字静音。
- 校准：用桌面版 `authenticity.analyze()` 对同一批样本跑基准，鸿蒙原生内核给出相同结论：
  - `01_yehangxing.flac`（1kHz 单音）：疑似假无损 0.55；
  - `03_sine_48k.wav`（785Hz 单音）：疑似假无损 0.55；
  - `04_sine24_96k.wav`（1.0s）：无法判定「时长过短，无法分析」（与桌面版 <2s 拒绝一致）。
- 有损格式与 ISO 统一落「无法判定 + 原因」；CUE 子轨解码母文件一次，结论复制到每个子轨。

### 6.4 CUE 分轨

- 起点/终点取自 CUE 帧（1/75s）；最后一轨终点用父文件总时长兜底。
- 原生 `exportSegment`：按解码帧 PTS 裁剪（兼容 seek 到关键帧之前），swr 转 16/24bit，FLAC/WAV 编码。
- 输出目录 `files/Exports/<专辑>/`，命名 `NN - 标题.flac`；写标签（CUE 元数据）、封面、`.lrc`，完成后自动扫描入库。
- 预间隙裁剪：设置「写入 → 分轨在下一轨 INDEX 00 处截止」开启后，每轨终点改到下一轨 INDEX 00（去掉轨尾静音预间隙）；导出前在间隙 10%/50%/90% 各取 ≤1s 解码为 16bit WAV 计算 RMS，>-75dBFS 视为藏有真实音频（隐藏曲/尾奏），自动保留不裁。DB v5 新增 `cue_pregap_ms` 保存 INDEX 00 起点。

### 6.5 SACD ISO（已实现，v1.3.6）

桌面版通过随包 `sacd_extract.exe -P` 读取 Master TOC/SACDText，再用 `-2 -s` 提取 DST 为 DSF。鸿蒙端没有可执行外部二进制的通道，改为：

- **曲目表**：`scanner/SacdParser.ets` 纯 ArkTS 读取 Master TOC（LSN 510，支持 2048/2064 字节扇区）、Area TOC（优先 `TWOCHTOC`，否则 `MULCHTOC`）、`SACDTRL2` 曲目表、`SACDTTxt` 逐轨标题与 `SACDText` 专辑/歌手；GBK 等编码按桌面版顺序兜底。
- **逻辑轨**：`CueIndexer.indexSacd` 把曲目表展开成与 CUE 子轨同构的行（`cuePath=ISO`、`cueStartMs/cueEndMs`），直接复用播放、分轨导出、队列与会话恢复。
- **解码**：FFmpeg 7.1.1 打入上游 SACD demuxer 补丁（PR #25936，LGPL），启用 `sacd`/`iff` 解复用与 `dst` 解码；`audio_stream_select.h` 优先选择 2 声道区并丢弃其他声道区，DST/DSD 两种帧格式均可解码。补丁与源码在 `tools/ffmpeg-ohos/patches/`，构建脚本自动应用。
- **导出**：位完美 DSF（1bit/2.8224MHz，LSB-first，4096 字节块 + ID3v2.3 标签/封面），DSD 原始字节直接落盘、DST 走 `dst` 解码器的 raw DSD 输出；另可选 24bit/176.4kHz FLAC/WAV（PCM）。DSF 音频与 `sacd_extract` 逐字节一致，DST 解码帧 CRC 与 FFmpeg FATE 参考一致。
- **边界**：SACD 镜像本身不参与真假无损鉴定（与桌面版一致，可先分轨再鉴定）；一键全自动仍跳过 ISO 行。
