# 音序管家 · 鸿蒙 PC v1.3「桌面界面 1:1 复刻」可执行计划

> 基线：`harmony-pc` @ `fa61800`（M2 出口回归通过）
> 对照：桌面版 `main` @ v1.8.2（Python + PySide6）
> 参考：`README.md`（桌面版）、`harmony/README.md`、`harmony/docs/REWRITE-PLAN.md`

## 0. 一句话目标

把鸿蒙版从「移动式单列页面」改成**和桌面版同一张工作台**：品牌条 → 操作栏 → 统计卡 → 曲库表格 + 右侧详情/参数 → 播放条 → 日志/歌词/信号路径 → 状态栏；交互按桌面版的手感做，做不到的能力明确删除，不摆假按钮。

**视觉命题**：深空蓝专业音频工作台 —— 近黑深底、玻璃质感面板、单一冰蓝强调色、密集但克制的数据行。
**内容计划**：主工作台（曲库）为唯一主角；辅助页只承担编辑、整理、体检、封面、歌词、EQ、关于。
**动效命题**：① 品牌条底部冰蓝渐变收口与静态星域；② 选中/播放行左侧强调条 + 淡强调底；③ 播放条玻璃卡与圆形播放键；④ 右侧面板与底部栏折叠。

## 6. 核心算法阶段（v1.3.1，1:1 复刻桌面版）

### 6.1 模块与入口

| 能力 | 鸿蒙实现 | 桌面版对应 |
|---|---|---|
| 联网元数据匹配 | `net/MetadataProviders.ets` + `net/TextMatch.ets` + `pipeline/Matcher.ets` + `components/MatchDialog.ets` | `core/matching.py` / `net/*.py` |
| 一键全自动 | `pipeline/AutoRunner.ets` + `Index.startAuto/saveAllPending` | `pipeline/batch.py` |
| 真假无损 / 频谱 | `cpp/audio_analysis.cpp` + `core/AuthenticityService.ets` + `components/SpectrumDialog.ets` | `core/authenticity.py` + `ui/spectrum.py` |
| 清理假无损 | `core/CleanupService.ets` + `files/Quarantine` | `core/quarantine.py` |
| CUE 分轨导出 | `pipeline/CueSplitService.ets` + 原生 `exportSegment` | `pipeline/cue_split.py` |
| SACD ISO | `scanner/Scanner.ets` 登记 + 明确提示 | `core/sacd.py`（依赖 `sacd_extract.exe`） |

### 6.2 匹配参数（与桌面版一致）

- 数据源优先级：网易云 → QQ 音乐 → MusicBrainz → iTunes；歌词：网易云 → QQ → lrclib。
- 评分权重：source 0.34 / title 0.28 / artist 0.20 / album 0.10 / duration 0.08。
- 默认自动应用阈值 62%（设置页可调 30–95%）；版本词惩罚 0.18；目录专辑 hint +0.14 / +0.05、冲突 -0.06。
- MusicBrainz：UA 标识 + 1.12s 限流，`artist-credit` 等连字符字段先转 camelCase 再解析。

### 6.3 鉴定参数与校准

- 采样：4 段 × 4s（DSD 2s），FFT 8192 点 Hann，s32 解码，双声道取功率较大者。
- PCM 判据：截止（峰值 -65dB）/ 陡度 / 250Hz 断崖（12dB）/ 扩展带（相对峰值与 300–3kHz 主体）/ 空洞 / sfb21 / 扩展带平坦度 / 升频台阶（18dB）/ 有效位深零填充。
- DSD 判据：50–100kHz 噪声整形斜率（≥6.0 真 / <0.5 假）、PCM Nyquist 断崖、CD 边界数字静音。
- 校准：用桌面版 `authenticity.analyze()` 对同一批样本跑基准，鸿蒙原生内核给出相同结论：
  - `01_yehangxing.flac`（1kHz 单音）：疑似假无损 0.55；
  - `03_sine_48k.wav`（785Hz 单音）：疑似假无损 0.55；
  - `04_sine24_96k.wav`（1.0s）：无法判定「时长过短，无法分析」（与桌面版 <2s 拒绝一致）。
- 有损格式与 ISO 统一落「无法判定 + 原因」；CUE 子轨解码母文件一次，结论复制到每个子轨。

### 6.4 CUE 分轨

- 起点/终点取自 CUE 帧（1/75s）；最后一轨终点用父文件总时长兜底。
- 原生 `exportSegment`：按解码帧 PTS 裁剪（兼容 seek 到关键帧之前），swr 转 16/24bit，FLAC/WAV 编码。
- 输出目录 `files/Exports/<专辑>/`，命名 `NN - 标题.flac`；写标签（CUE 元数据）、封面、`.lrc`，完成后自动扫描入库。
- 预间隙裁剪：设置「写入 → 分轨在下一轨 INDEX 00 处截止」开启后，每轨终点改到下一轨 INDEX 00（去掉轨尾静音预间隙）；导出前在间隙 10%/50%/90% 各取 ≤1s 解码为 16bit WAV 计算 RMS，>-75dBFS 视为藏有真实音频（隐藏曲/尾奏），自动保留不裁。DB v5 新增 `cue_pregap_ms` 保存 INDEX 00 起点。

### 6.4b 批处理与桌面版对齐（v1.3.2）

- 文件名兜底：标签为空或只有文件名时，按「歌手 - 歌名」与去前导序号规则生成检索词，再进行联网匹配。
- 本地歌词优先：内嵌歌词或同名 `.lrc` 命中时不请求在线歌词，避免覆盖与浪费配额。
- 专辑一致性：同目录匹配完成后按「专辑 + 年份」多数投票收敛，再统一写入，避免一张专辑出现多个发行版。
- 标签写回新增 WAV：在 RIFF 中增量写入/替换 `ID3 ` chunk，不动 fmt/data；写后回读校验标题/歌手/专辑/时长，失败自动回滚并保留 `.bak`。已用外部 ffmpeg 验证：`title/artist/album` 可读、6.00s PCM 48k 立体声完整。
- 封面：WAV 的 APIC 支持写入与解析，`ensureCover` 可从 WAV 回填封面缓存。
- 自动重命名：设置页可开关并编辑模板（默认 `{artist} - {title}`，同时支持中文 `{歌手} {歌名} {专辑} {年份} {曲目}`）；写回阶段结束后执行，CUE 母文件跳过、同名 `.lrc` 跟随改名、DB 路径与搜索 blob 同步更新。实测 2/2 成功：WAV/MP3 均按模板改名，CUE 母文件保持不变。
- 封面/歌词兜底：MusicBrainz 候选通过 Cover Art Archive（`release/{id}/front-500`）取图；候选无图时按「专辑 + 歌手」走 iTunes/网易云相册搜索；歌词全源未命中且歌手非空时只按歌名再试一轮。WAV 已实测可写入并回读 300×300 APIC 内嵌封面。
- 标签字段补齐（DB v4）：新增 `albumartist / disc_no`，FLAC（ALBUMARTIST/DISCNUMBER）、MP3（TPE2/TPOS）、WAV（ID3 TPE2/TPOS）、M4A（aART/disk）读写；匹配应用、标签编辑页、详情面板与重命名模板（`{albumartist}`/`{disc}`）同步接入。WAV 实测外部 ffmpeg 回读 `album_artist` 正确、时长与 PCM 未变。

### 6.4c 多选（v1.3.3）

- 行点击读取 `ClickEvent.getModifierKeyState(['Ctrl'|'Shift'])`：Ctrl 切换单行，Shift 以最近一次点击为锚点选择连续区间，普通点击回落单选并重置锚点。
- 表格按选中集合高亮，底部状态栏显示「已选 N 首」；筛选或扫描后自动剔除已不在当前列表中的选中项。
- 多选时批量操作作用于选中集合：「移除 / 删除选中」确认后批量移出曲库（不删文件）；「真假鉴定」「一键全自动」优先只处理选中曲目；「清理假无损」只在选中集合内隔离。多选为 1 首或未多选时保持原有全量/筛选范围语义。
- 模拟器 CLI 只能注入触摸点击，无法附带 Ctrl/Shift 修饰键；多选逻辑已通过编译与单选回归，实际组合键需在 2in1 真机/模拟器用鼠标键盘手动复核。

### 6.4d 主题系统（v1.3.4）

- 调色板：`theme/ThemeStore.ets` 内置桌面版 11 套主题（深空 / 黑胶 / 春 / 夏 / 秋 / 冬 / 海岸 / 暮光 / 太极 / 纸白 / 黑白极简），深空保留原 Token 精确取值，其余按桌面版 `_dark`/浅色参数生成面板、卡片、输入、悬浮、选中与状态色。
- 组件取色：`Tokens.ets` 由只读常量改为可写静态字段，并新增品牌条、弹层、表格、播放条、日志栏、多选行等半透明派生色；桌面工作台、弹层与子页的硬编码色已全部替换为 Token，浅色主题下不会残留深色块。
- 切换流程：参数 → 外观 → 选择主题 → 保存参数；写库后套用调色板并 `replaceUrl` 重建工作台，冷启动读取 `ui_theme` 自动恢复（必要时先套色再重建一次）。会话队列在重建前保存，主题切换不丢播放进度。

### 6.4e 桌面能力补齐（v1.3.5）

- 批量编辑标签：多选/右键进入标签编辑页，一次写回多首；CUE 子轨自动跳过。
- 撤销标签编辑：读取写回时保留的 `.bak` 覆盖原文件并重新扫描入库；使用系统 `copyFileSync`，避免大文件拷贝卡死。
- 去除标题序号：规则与桌面版 `core/clean.py` 对齐（1~2 位数字 + 点/顿号/连字符/空格/括号），只改标题前缀，写回文件与数据库。
- 导出处理报表：CSV（UTF-8 BOM），列含状态/标签/规格/判定/置信度/路径；优先系统「保存」选择器，失败回退 `files/Reports`。
- 封面导出：`Exports/Covers` 批量导出（文件名含歌手/专辑），或为每个目录生成 `cover.jpg/png`。
- 隔离区管理：列出 Quarantine 条目，恢复（含 `.lrc` 侧车）后自动扫描入库，支持单条删除与清空。
- 队列与路径：右键/更多菜单支持「下一首播放」「加入队列」「复制完整路径」。
- 修复拷贝死循环：`fs.readSync` 的 `offset` 是文件偏移而非缓冲区偏移，循环读 1MB 块会反复读同一段；备份恢复与导入改用 `copyFileSync`（导入保留无 offset 的顺序读写兜底）。

### 6.5 SACD ISO 边界

桌面版通过随包 `sacd_extract.exe -P` 读取 Master TOC/SACDText，再用 `-2 -s` 提取 DST 为 DSF。鸿蒙端没有该二进制，FFmpeg 也没有 SACD ISO demuxer / DST 解码器。当前策略：扫描到 `.iso` 登记为待处理行并提示「可先用桌面版导出 DSF」，不做假成功。

## 7. 风险与兜底

- ArkTS 严格模式：禁止 `any`、匿名对象类型；所有跨文件数据结构用 `class`/`interface` 显式声明。
- `@State` 数组代理跨 NAPI 会变空：EQ 已按旧经验先复制普通数组，界面代码沿用。
- 桌面级密集布局在 2in1 模拟器 1560vp 宽下验证；小于 1180vp 隐藏右侧面板，避免列被压扁。
- 大曲库列表用 `List` + `LazyForEach` 可后续替换；v1.3 先 `ForEach`，以千首内为验收规模。
- 主题：11 套已接入，所有颜色走 `Tokens.ets`；新增主题只需在 `ThemeStore` 补一条调色板。
