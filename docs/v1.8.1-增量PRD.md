# 音序管家 v1.8.1 增量 PRD

版本 1.8.1（承接 1.8.0）｜中文｜Py3.13 + PySide6 + sounddevice 0.5.6(PortAudio V19.7.0-devel) + ffmpeg｜基线 `D:/SeqAudio Manager`｜GPL-3.0-or-later

原始需求：①设备增删即时刷新 ②信号路径随设置/切歌刷新 ③ASIO 测试后端（TempoTec USB Audio，驱动已装）④DSD64–1024 直出与 Native DSD 可行性 ⑤版本号仍为 v1.8.1

## 1. 目标与本期不做

**目标**：设备列表与信号路径所见即时为真，ASIO 与 DSD DoP 直出作为可选通路；做不到的显式回退并写明原因，不静默降级。

| 不做项 | 立场 |
| --- | --- |
| Native DSD 直出 | PortAudio 无 DSD 端点，需厂商私有 ASIO 扩展；仅 P2 出结论。 |
| DSD1024 / DoP512 | 本机 ASIO 上限 352.8 kHz，载体率不足。 |
| DoP256 实现 | 需 705.6 kHz 载体，实测被拒；只留能力探测。 |
| 自编译/分发 ASIO SDK | Steinberg 专有许可与 GPL 冲突；仅用 wheel 自带 `libportaudio64bit-asio.dll`，不编译、不打包、不给下载指引。 |
| 位完美类承诺 | 延续 R2 措辞铁律，`assert_wording()` 拦截。 |

## 2. 硬约束（实测，不得推翻）

1. 默认 PortAudio 不含 ASIO；`SD_ENABLE_ASIO=1` **在 import sounddevice 前**生效才出现 ASIO hostapi，且需同目录 `libportaudio64bit-asio.dll`。
2. 可枚举 `TempoTecUSBAudio ASIO Driver`（2ch，默认 44100），44100/2ch 开流成功，延迟 ≈304 ms。
3. 可用率 44100/48000/88200/96000/176400/352800；**705600、1411200 不可用** → DoP64/DoP128 可行，DoP256 不可行。
4. 现状：DSD 经 ffmpeg 转 PCM，无位流直读；已有 `playback_dsd_pcm_rate`(176400)、`playback_int_pipeline`、`playback_dsp_bypass`、`playback_volume_mode`。
5. 四档后端与按后端过滤设备已于 1.8.0 完成；`constants.py` 已含 `BACKEND_ASIO`。

## 4. 关键取舍与风险

| 风险 | 决策 |
| --- | --- |
| 变量时机（进程级） | `run.py`/`app.py` 最顶部 `os.environ.setdefault("SD_ENABLE_ASIO","1")`，先于任何 import sounddevice；提供 `--no-asio`。 |
| 启用失败 | `backend_present("asio")` 为 False 即置灰；配置存 asio 却解析不到时 `resolve_backend` 返回 -1（出声优先）+ WARNING + 面板提示。 |
| 独占抢设备 | 复用「暂停即释放」，切后端/设备前先关流，沿用现有独占文案。 |
| 延迟 ≈304 ms | 面板显示实测值；>350 ms 提示，不自动改 buffer。 |
| 许可证 | 仅动态用 wheel 自带二进制；`THIRD-PARTY.md` 补记来源与「未分发 SDK」；自编译须先法务结论。 |
| DoP 前提 | 固定 int24/int32 容器、禁 follow-source 重采样、强制 DSP 旁路，冲突项置灰。 |
| 率上限 | DSD256+ 源回退 PCM，UI 写「设备不支持 705.6 kHz 载体」。 |
| 轮询开销 | 3 s 间隔、仅 GUI 定时器线程、播放中不重开流；拔出优先用 `DeviceLostError` 兜底。 |
